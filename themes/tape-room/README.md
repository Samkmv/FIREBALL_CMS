# Tape Room

Самостоятельная тема FIREBALL CMS. Главная страница — перенесённый целиком экран аудиоплеера Tape Room. Разметка плеера находится в `partials/player.php`, его стили, скрипты, иллюстрации и шрифт — в `assets/`. Тема не наследует шаблоны, фрагменты и ресурсы Default (`inheritDefault: false`).

Для работы нужен активный плагин `reel-player`: он хранит коллекции и обслуживает защищённые API и аудио. Активируйте тему Tape Room в **Админка → Темы**. Поле `homepage: "home"` в манифесте закрепляет плеер на корне сайта независимо от обычной настройки главной страницы. Гость перенаправляется на собственную страницу входа темы; после входа, регистрации и подтверждения 2FA пользователь попадает на главную.

`/admin/reel-player` показывает обзор, статистику пользователей, отправленные альбомы и модерацию; `/admin/reel-player/genres` — библиотеку жанров. Рабочие запросы плеера используют `/tape-room/api`, аудио и обложки — `/tape-room/media` и `/tape-room/catalog`. Доступ имеют все вошедшие пользователи. Личные записи и коллекции по-прежнему проверяются по владельцу; пользователь отправляет собственный альбом на модерацию. Администратор или создатель одобряет / отклоняет его; в общем каталоге появляются только одобренные альбомы. Глобальные настройки Google доступны создателю сайта.

Ранее зарегистрированный адрес Google OAuth `/admin/reel-player/drive/callback` сохранён и требует входа без административной роли. После подключения Google возвращает пользователя на главную страницу. Старые административные API и адреса ресурсов сохранены для уже открытых вкладок.

Страницы входа, регистрации, восстановления доступа, аккаунта, обычной CMS-страницы и публикации оформлены собственными шаблонами. Для пока отсутствующих шаблонов используется собственная страница 404.

Жанры доступны в редакторах альбомов и песен, с поиском по библиотеке. Раздел жанра учитывает собственную музыку и одобренный каталог; чужие черновики туда не попадают. На главной странице рядом с названием показана метка «Бета» в цветах выбранной темы.
