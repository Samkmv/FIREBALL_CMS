# Cartzilla Icons

Локальная копия набора Cartzilla Icons из `themes/default/assets/icons/` этого проекта. Tape Room использует собственные файлы CSS и WOFF2 и не обращается к ресурсам Default или CDN.

Каталог и названия классов: https://cartzilla-html.createx.studio/docs/icons.html

Подключение: https://cartzilla-html.createx.studio/docs/icon-font.html

Соответствие компонентов иконкам задаётся в `includes/icon-map.php`; примеры отображаются в `/tape-room/ui-kit#icons`. Та же карта используется кнопками плеера, каталога, песен и его окон. Иллюстрации катушек остаются SVG-декором.
