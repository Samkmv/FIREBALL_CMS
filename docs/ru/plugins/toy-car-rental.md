# Toy Car Rental

`Прокат машинок` — бизнес-плагин FIREBALL CMS для проката детских машинок. Название и описание карточки в каталоге переведены на русский, английский, немецкий и китайский языки.

## Назначение

Плагин позволяет оператору:

- выдавать машинку в прокат;
- запускать фиксированную или поминутную поездку;
- видеть активные поездки;
- получать визуальное и звуковое напоминание о просрочке;
- завершать поездку;
- учитывать оплату;
- смотреть статистику за сегодня.

## Установка и активация

1. Откройте `Админка → Плагины`.
2. Найдите `Прокат машинок` (название зависит от языка интерфейса).
3. Нажмите `Установить`.
4. Нажмите `Активировать`.

После активации в меню админки появится пункт `Прокат машинок`.

## Добавление машинок

Откройте `Прокат машинок → Машинки → Добавить машинку`.

Для машинки задаются:

- название;
- номер;
- цвет;
- статус;
- цена за минуту;
- изображение;
- порядок вывода.

## Запуск поездки

На странице `Панель оператора` показываются компактные карточки: название, статус, цена за поездку и цена минуты. Цвет и подробные формы на карточках не выводятся.

У свободной машинки две круглые кнопки:

- **Фиксированная** — выберите длительность в небольшом списке и нажмите кнопку с треугольником. По умолчанию доступны 5, 10, 15 и 30 минут; список и длительность по умолчанию меняются в настройках. Сумма равна выбранной длительности × цене минуты. Цена минуты берётся из машинки, при отсутствии — из общих настроек. Сумма сразу пересчитывается на карточке при выборе длительности и фиксируется сервером при старте. Быстрый старт фиксированной поездки сохраняет оплату наличными со статусом «Оплачено».
- **Поминутная** — кнопка с часами сразу запускает поездку без итоговой суммы и оплаты. Стоимость минуты берётся из машинки, при отсутствии — из общих настроек.

Старт отправляется асинхронно. На этой же карточке сразу появляются цифры таймера и кнопка завершения. Повторный запуск блокируется в интерфейсе и на сервере. Без JavaScript формы работают через обычную отправку и переход на панель.

После старта создаётся запись в `toy_rental_rides`, а машинка получает статус `rented`.

Отдельная цена фиксированной поездки не задаётся. Например, при цене минуты 25 ₽ поездка на 5 минут стоит 125 ₽, на 10 минут — 250 ₽, на 15 минут — 375 ₽. Изменение тарифа влияет на новые поездки; суммы уже запущенных поездок и истории сохраняются.

## Поминутная аренда

В поминутном режиме итоговая сумма на старте не вводится. Система считает время вверх от `started_at`, показывает примерную стоимость и сохраняет `payment_status = unpaid`.

При завершении сервер считает:

- фактические минуты с округлением вверх;
- `final_amount` как системно рассчитанную сумму;
- `payment_amount` как фактически оплаченную сумму, которую оператор может поправить вручную.

## Таймер и просрочка

`assets/toy-rental.js` обновляет таймеры каждую секунду, используя серверное время. Карточки и статистика синхронизируются без перезагрузки страницы каждые 5 секунд либо с заданным интервалом автообновления.

Когда фиксированное время заканчивается:

- таймер останавливается на `00:00`;
- карточка получает статус `Просрочена`;
- появляется сообщение с названием машинки;
- проигрывается короткий звук, если он включён и браузер разрешает аудио;
- создаётся непрочитанное уведомление в общей системе CMS;
- через штатный `NotificationService` отправляется Web Push администраторам и создателям с включёнными уведомлениями.

Окончание фиксированного времени не подтверждает возврат машинки: оператор закрывает поездку кнопкой завершения. Чтобы забытые поездки не работали бесконечно, максимальная длительность по умолчанию — **120 минут**. Её можно изменить от 1 до 1440 минут; предел должен быть не меньше всех фиксированных длительностей. При достижении предела любая активная поездка автоматически закрывается, машинка становится доступной, оператор получает уведомление и должен проверить фактический возврат.

Поминутная сумма и фактическая длительность ограничены этим пределом, даже если фоновая проверка запустилась позже. Автоматическое завершение не отмечает неоплаченную поездку как оплаченную: долг остаётся в истории. При отключении или удалении через жизненный цикл CMS открытые поездки закрываются. При повторной активации старые поездки, превысившие предел, закрываются без повторной рассылки уведомлений.

### Уведомления при закрытой панели

Плагин регистрирует задачу `toy_rental_expiry` в общем планировщике CMS. На сервере нужно запускать штатный планировщик раз в минуту:

```cron
* * * * * cd /path/to/FIREBALL_CMS && /path/to/php bin/cms.php scheduler:run
```

При открытой панели окончание отправляется на сервер сразу; при закрытой — обрабатывается фоновой задачей с точностью до минуты. Не запускайте несколько независимых планировщиков для одной CMS. Перед настройкой проверьте, не подключён ли общий планировщик уже для других плагинов.

Для доставки на телефон должны быть настроены PWA/Web Push и VAPID в CMS, разрешены уведомления в профиле администратора и на устройстве. Переключатель «Push при просрочке» управляет отправкой push; уведомление в центре CMS сохраняется и при выключенном переключателе. Повторные проверки не создают повторное уведомление об одном окончании.

## Завершение поездки

Круглая кнопка завершения фиксированной поездки сразу сохраняет результат. Для поминутной поездки открывается отдельное окно с фактическими минутами, расчётом, итоговой суммой, способом и статусом оплаты. Если сумму не правили вручную, сервер рассчитывает её на момент завершения. Без JavaScript поминутная поездка закрывается с серверным расчётом и остаётся неоплаченной до отметки в истории.

Завершение без перезагрузки:

- записывает `ended_at`;
- считает фактическую длительность;
- считает итоговую сумму для поминутной аренды;
- ставит поездке `completed`;
- возвращает машинку в `available`;
- сохраняет оплату.

## История

Раздел `История` поддерживает фильтры:

- сегодня;
- вчера;
- период;
- машинка;
- тип аренды;
- способ оплаты;
- статус оплаты.

## Статистика

Раздел `Статистика` показывает:

- количество поездок сегодня;
- фиксированные поездки;
- поминутные поездки;
- активные поездки;
- завершённые поездки;
- просроченные поездки;
- выручку только по оплаченным поездкам;
- выручку наличными;
- выручку картой;
- среднюю длительность;
- популярную машинку.

## Настройки

Раздел `Настройки` хранит значения через `plugin_settings`:

- варианты фиксированных длительностей (например, 5, 10, 15, 30 минут);
- длительность по умолчанию, которая должна входить в список;
- максимальная длительность для защиты от забытых таймеров;
- цена минуты по умолчанию;
- валюта;
- звук;
- push-уведомления;
- интервал асинхронного обновления панели оператора.

## Переводы

Все строки интерфейса плагина находятся в `plugins/toy-car-rental/lang/`. Плагин не добавляет свои переводы в основные файлы `app/Languages`.
