# Страница аналитики

Изменена только отдельная страница `/admin/analytics`, расположение виджетов обзора не затронуто.

- Начиная с ширины 1200 px две таблицы занимают равные половины строки. На меньших экранах панели располагаются вертикально, на телефоне используются стандартные карточки CMS.
- Фильтры собраны в компактную сетку. При фильтрации и поиске обе таблицы возвращаются на первую страницу; сортировка и пагинация одной таблицы сохраняют состояние другой.
- У посетителей три группы: время и страна, устройство/ОС и браузер, страница и источник. Все шесть вариантов сортировки сохранены.
- Панели содержат общее число отфильтрованных страниц/визитов, собственную пагинацию по 20 записей и прокрутку с закреплённым заголовком. Длинные адреса переносятся, а не расширяют страницу.
- Полоска под числом просмотров показывает долю страницы среди всех визитов, соответствующих текущему фильтру, а не только видимых строк. Числа по-прежнему берутся из тех же запросов репозитория.

Проверка: `tests/full_analytics_browser.cjs` рендерит настоящее представление и общие компоненты на изолированных данных из CLI-only fixture `tests/fixtures/full_analytics.php`. Проверяются четыре языка, оба цветовых режима, экраны 320–1996 px, экранирование адресов, пустые результаты, независимая пагинация и обновление таблиц без перезагрузки. Используются основной контроллер таблиц и два варианта резервного контроллера CMS. База сайта не изменяется.
