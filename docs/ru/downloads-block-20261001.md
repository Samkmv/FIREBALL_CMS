# Блок «Загрузчик» — 01.10.2026

Добавлен отдельный тип `downloads` в существующий блочный редактор. Общая навигация, панели, остальные блоки и оформление CMS не переделывались.

## Использование

Добавьте блок «Загрузчик». Перетащите файлы в его область, нажмите «Загрузить с устройства» либо «Выбрать из файлового менеджера». Существующий файловый менеджер выбирает один файл за раз; его можно открыть повторно для добавления следующего файла.

В правой панели задаются заголовок, необязательное описание, отображение иконок типов и размеров файлов. В строках списка доступны перемещение вверх/вниз и удаление из блока. Удаление строки **не удаляет файл из файлового менеджера**, поскольку этот файл может использоваться в других записях.

На публичной странице выводится карточка CMS со списком и кнопками скачивания. Пустой блок не публикуется. Переводы добавлены для русского, английского, немецкого и китайского языков.

## Изменённые файлы

- `app/Modules/BlockEditor/BlockEditorService.php` — регистрация типа, настройки загрузки и подписи интерфейса.
- `public/assets/default/js/editor2/editor.js` — отображение блока/инспектора, файловый диалог, перетаскивание, выбор через менеджер, порядок файлов и сохранение. Незавершённая загрузка блокирует публикацию; успешные файлы сохраняются даже при ошибке следующего файла.
- `app/Modules/BlockEditor/BlockEditorController.php`, `config/routes.php` — отдельный административный маршрут загрузки с действующими auth/admin/CSRF-проверками.
- `app/Models/FileManager.php` — открытый доступ к существующему списку разрешённых расширений без изменения правил загрузки.
- `app/Views/themes/default/admin/file_manager_browser.php`, `public/assets/default/js/admin-file-manager.js` — имя и размер в ответе выбора, совместимом с существующими изображениями/галереями.
- `app/Modules/BlockEditor/BlockRenderer.php` — публичный вывод из JSON и сохранённого состояния редактора, экранирование названий и проверка ссылок.
- `public/assets/default/css/block-editor.css` — локальное оформление области загрузки, кнопок и описания в инспекторе.
- `public/assets/default/css/style.css`, `themes/default/assets/css/style.css` — одинаковые стили нового блока с цветами/кнопками шаблона, мобильной раскладкой и переносами длинных названий.
- `app/Languages/ru.php`, `en.php`, `de.php`, `zh-cn.php` — переводы нового блока.
- `tests/editor2_fixture.php`, `tests/editor2_reliability.cjs` — регистрация блока в тестовом редакторе и проверки асинхронной загрузки.
- `tests/downloads_block.php`, `tests/downloads_browser.cjs`, `tests/downloads_upload.cjs`, `tests/downloads_upload_fixture.php` — новые проверки публичного вывода, интерфейса и реальной HTTP-загрузки.

## Проверки

- PHP: публичный renderer и реальная HTML-санитизация, JSON/HTML snapshot, переключатели, пустой блок, запрещённые URL и экранирование, сохранение типа и наличие переводов.
- Изолированный HTTP-тест: настоящая multipart-загрузка через новый контроллер и файловый менеджер. Проверены имя/размер, каталоги записей/страниц, отсутствие перезаписи и отказы для запрещённого расширения, поддельного PDF, пустого и слишком большого файла. Запись велась только во временную папку, не в загрузки сайта.
- Chromium: диалог выбора, перетаскивание, callback файлового менеджера, порядок/удаление, правый инспектор, сохранённое состояние и публичная карточка на 320, 390, 430, 768 и 1440 px, в обеих темах; проверены отсутствие горизонтального переполнения, контраст и кнопки не меньше 44 px.
- Регрессия существующего редактора: ввод, история, порядок/скрытие/удаление, галерея, панели и PWA-геометрия на ширинах 320–1920 px.
- Асинхронность: частичный успех, сохранение текущего выделения, запрет публикации до завершения загрузки и отсутствие восстановления удалённого блока после позднего ответа.
- PHP/JS-синтаксис и `git diff --check`.

## Границы проверки

Проверки выполнялись локально и на изолированных тестовых страницах, без записи в базу CMS. Реальный iPhone Safari/PWA не использовался — его системный файловый диалог требует проверки на устройстве. Миграция базы не нужна. Изменения не опубликованы на боевом сайте.
