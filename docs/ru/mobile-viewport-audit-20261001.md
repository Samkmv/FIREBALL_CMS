# Чат и редактор: мобильный viewport, 01.10.2026

## Что обнаружено

1. В расчёте чата размер клавиатуры определялся через `referenceHeight - visualHeight - offsetTop`. При сильном смещении Safari `offsetTop` компенсировал уменьшение высоты: клавиатура могла ошибочно считаться закрытой, а нижний safe-area отступ возвращался. Координата viewport теперь не участвует в определении высоты клавиатуры.
2. Документ чата блокировался только через `overflow:hidden`. Для iOS этого недостаточно: нативный корневой scroll view может двигаться при открытой клавиатуре. См. [WebKit 292603](https://bugs.webkit.org/show_bug.cgi?id=292603). Это связанный браузерный риск, а не подтверждение точной причины на устройстве пользователя.
3. В публичном CSS редактора и его копии в теме оставалось `height:100lvh` для PWA. Обработчики `visualViewport` редактора перемещали контекстные меню, но не меняли размер рабочего экрана. Панель настроек поэтому могла оставаться привязанной к экрану за клавиатурой.

## Изменения

- `public/assets/default/js/app-viewport.js`: общий opt-in контроллер только для полноэкранных приложений. Фиксирует body, отключает лишний PWA min-height, читает видимый viewport, объединяет события в один animation frame. Вертикальные жесты разрешены внутри прокручиваемых областей; на их границах предотвращается передача жеста корневой странице. Выделение текста, горизонтальные жесты и масштабирование не запрещены. При отключении контроллера/переходе к desktop исходные inline-стили возвращаются.
- `public/assets/default/js/chat-viewport.js`: адаптер чата к общему контроллеру. Шапка и чат используют одну систему координат. Существующее сохранение позиции сообщений остаётся в `chat.js` и `chat-group.js`.
- `app/Controllers/ChatController.php`: общий контроллер загружается перед адаптером для личного и группового чата; URL обоих файлов версионируются.
- `app/Modules/BlockEditor/BlockEditorService.php`: контроллер загружается перед кодом редактора.
- `public/assets/default/js/editor2/editor.js`: размер workspace синхронизируется с viewport; при видимой клавиатуре нижний safe-area резерв равен нулю. При уничтожении редактора слушатели и блокировка освобождаются.
- `public/assets/default/css/block-editor.css` и `themes/default/assets/css/block-editor.css`: удалена высота через `100lvh`. Панель настроек привязана к форме внутри фиксированного workspace, а не к отдельному layout viewport; её содержимое сохраняет внутреннюю прокрутку.

## Границы проверки и риски

Клавиатура и смещение `visualViewport` в браузерных тестах моделируются. Настоящего iPhone/PWA здесь нет; тестовый WebKit не поддерживает установленную macOS. Нужно проверить на устройстве открытие/закрытие клавиатуры, переключение приложения, поворот, выделение текста и прокрутку до границ. Проверка desktop выполнена в Chromium, не в Safari desktop.

Общий контроллер не подключён к обычным публичным страницам и не меняет эффект стекла поиска. Не добавлены отрицательные `bottom`, циклы `window.scrollTo` или новые z-index. Изменения локальные; на боевой сайт не опубликованы.
