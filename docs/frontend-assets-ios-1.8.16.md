# Bootstrap и иконка установки iOS — 1.8.16

В подключаемых локальных сборках Bootstrap оставались завершающие комментарии
`sourceMappingURL`, но соответствующие файлы `.map` не поставлялись. При открытых
инструментах браузер мог запрашивать их и получать 404. Из используемых JS/CSS
Tape Room и стандартной темы, включая копии для админки, удалены только эти
комментарии. Код, стили и лицензии сохранены. Скрипт подготовки Tape Room повторяет
обработку после замены Bootstrap. Проверка библиотеки восстанавливает удалённый
комментарий в памяти и сверяет официальный SHA-384.

Apple Touch Icon больше не подключается через `rel="preload"`: картинка нужна
установщику приложения, а не для отрисовки страницы. Обычная ссылка
`rel="apple-touch-icon" sizes="180x180" type="image/png"` сохранена.

В `PwaService::headData()` для установщика теперь указывается прямой адрес
проверенного PNG-файла с версией содержимого. Для пользовательского набора это
`/uploads/pwa/generated-…/apple-touch-icon.png?v=…`, для стандартного оформления
Tape Room — PNG из активной темы. При смене картинки меняется адрес в HTML.
Это устраняет использование одного и того же адреса для разных вариантов иконки.
Корневые `/apple-touch-icon.png` и `/apple-touch-icon-precomposed.png` продолжают
отдавать выбранный PNG без авторизации, с поддержкой HEAD и проверки ETag.

Схема хранения, генерация и пользовательские файлы иконок не меняются. Ручная
миграция не нужна. Для боевой установки требуется обновить CMS, а не только
метаданные плагина: PWA-заголовки формируются общим движком. После обновления
страница должна объявлять прямой PNG с версией вместо неизменного корневого URL.

На момент диагностики tape-room.ru отдавал корректный PNG 180×180 как по
корневому, так и по прямому адресу пользовательского набора. Отсутствие картинки
в системном диалоге iPhone этим HTTP-тестом не воспроизведено; кэш Safari остаётся
возможной причиной, а не установленным фактом. Изменённое подключение требует
проверки после обновления на физическом устройстве. Ранее добавленные ярлыки
могут сохранять старое изображение.

Apple описывает PNG и `apple-touch-icon` в [руководстве Safari](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html).

Проверки:

- `python3 tests/pwa_installation_check.py`: выбранные и стандартные PNG,
  прямые ссылки, смена URL, отсутствие preload, GET/HEAD, ETag, манифест,
  отсутствие перезаписи системных иконок. Используется изолированная установка
  внутри `tests/.tmp/`.
- `python3 tests/tape_room_bootstrap_check.py`: отсутствие ссылок на карты,
  контрольные суммы библиотеки, формы и доступ к UI-библиотеке. Нужен тестовый
  сервер Tape Room на указанном в сценарии адресе.

Версия CMS: 1.8.16. Версия Tape Room: 1.7.6.
