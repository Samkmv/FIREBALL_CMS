# Коммерция для FIREBALL CMS

Поместите каталог `commerce` в `plugins/` и установите и активируйте плагин в разделе **Плагины**. CMS применит миграцию при установке. Данные магазина сохраняются при деактивации.

- **Коммерция → Настройки магазина** — название витрины, адрес самовывоза, доступность и стоимость доставки.
- **Коммерция → Категории / Товары** — каталог, фотографии, цены и остатки. Витрина доступна по адресу `/shop`.
- **Коммерция → Заказы** — подтверждение, выдача или доставка, отметка об оплате, завершение и отмена. Отмена возвращает остаток на склад. Оплата и возврат фиксируются после фактического расчёта с покупателем.
- **Обзор CMS** — виджет с новыми заказами, количеством товаров и низким остатком.
- **Настройки сайта → Главная страница → Витрина магазина** — вывод каталога по адресу `/`. Этот пункт доступен с поддержкой `site_homepage_modes` в движке и при активном плагине.

Цены хранятся в копейках и отображаются в рублях. Поддерживается расчёт при получении. Содержимое и сумма заказа сохраняются в момент оформления. Гость видит карточку заказа в сессии оформления. Авторизованный покупатель видит свои заказы в профиле.

Витрина использует общие стили FIREBALL CMS на основе Cartzilla. Фотографии товаров загружает администратор.

## Главная и поиск

Главная магазина доступна по `/shop/home`. Чтобы показывать её в корне сайта, выберите «Витрина магазина» в настройках сайта. Каталог и результаты поиска находятся в `/shop`. Поле в шапке витрины ищет по названию и артикулу и показывает подсказки. На остальных страницах CMS шапка использует поиск по сайту.

- В разделе «Слайдер» задайте изображение, заголовок, текст кнопки, категорию и порядок показа.
- В разделе «Категории» загрузите круглые фотографии. Под каждой категорией показывается до трёх её товаров.
- Популярные товары идут после категорий. Отмеченные в админке товары идут первыми, затем учитываются оплаченные и завершённые продажи. Для карточки можно добавить второе фото. Для цветовых вариантов создайте отдельные товары с одинаковой группой вариантов.

Поиск по товарам из шапки зависит от фильтра `public_navigation_search` в публичной теме CMS.

## Карточка товара

Карточка открывается по прежнему адресу `/shop/product/<slug>`. Вкладки «Характеристики» и «Отзывы» имеют свои адреса. В форме товара можно выбрать сразу несколько фотографий. Галерея показывает основное фото, фото при наведении и до 12 дополнительных кадров. Если основного фото нет, первым становится первое фото галереи. Характеристики добавляются в этой же форме, по одной строке на параметр.

Авторизованный покупатель может оставить один отзыв на товар после завершения оплаченного заказа. Отзыв появляется на витрине после публикации в разделе **Коммерция → Отзывы**. Рейтинг учитывает только опубликованные отзывы. Недавно просмотренные товары сохраняются на время сессии.

Корзина открывается из шапки витрины в выдвижной панели. Счётчик, количество и сумма обновляются после серверной проверки остатка. Кнопка «Вся корзина» открывает привычную страницу корзины. Для панели в шапке используется фильтр `public_navigation_cart` в стандартной теме CMS.

В форме товара переключатель «Отметить как новинку» управляет бейджем, а поле «Цена до скидки» показывает прежнюю цену и процент скидки. Сумма заказа считается по текущей цене. Избранное доступно через меню профиля и по адресу `/shop/favorites`.
