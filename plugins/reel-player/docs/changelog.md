# Change Log и сверка дорожной карты

Страница `/tape-room/changelog` доступна администратору и создателю в активной теме Tape Room, как и `/tape-room/ui-kit`. Ссылки находятся в общем боковом меню и вкладках документации на обеих страницах. Посторонние пользователи не получают содержимое страницы. Переход поддерживается штатным непрерывным мини-плеером без отдельной загрузки аудио.

Данные хранятся в `resources/changelog.php` плагина; представление — в `themes/tape-room/templates/changelog.php`. При выпуске нужно добавить запись с датой, названием, пунктами `added`, `fixed`, при необходимости `notes`. Версии в шапке читаются из установленных манифестов, а количество записей и статусов рассчитывается по данным. CSS входит в оболочку, поэтому страница оформлена и при обычной загрузке, и при переходе без перезапуска плеера.

## Источники истории

История охватывает сохранённые изменения `plugins/reel-player/plugin.json` с 9 октября 2026 года. Источники: Git-коммиты, русские заметки выпусков, README плагина и темы, миграции и текущая реализация. Версии 1.7.1–1.7.2 и 1.7.7–1.7.8 объединены; версии 1.7.3–1.7.5 описаны в README темы и сохранены в общей истории коммита `4c7b6776`. Отсутствующие в Git промежуточные номера до 1.2.5 не выдумываются.

Архивная сборка `2.0.0-rc.1` из `af9c73ea` убрана из main в `cded4ad1`. Её персональные рекомендации, лицензированное скачивание и тарифы нельзя перечислять среди возможностей текущего main. Она показана отдельной архивной записью.

Связанные исправления PWA, Composer, резервирования и восстановления CMS описаны отдельным блоком, без присвоения версии плагина изменениям движка.

## Статусы возможностей

- `done` — возможность существует в текущей реализации; важные границы указаны в описании.
- `partial` — есть реализация, но остаются явно перечисленные ограничения или обязательная проверка на реальном устройстве.
- `absent` — такой возможности в текущем плеере нет. Это не обещание включить её в ближайший выпуск.

При подготовке страницы ссылка на чат «Дорожная карта аудиоплеера» была прочитана через приложение. Вместо обоих ответов сервис вернул только `chatgpt-content-reference`, без текста дорожной карты; веб-страница требует отдельного входа. Поэтому `roadmap_source` равен `awaiting-original`, интерфейс прямо сообщает об этом, проценты исполнения исходного плана и согласованные сроки не выводятся. После получения исходного текста его пункты нужно сопоставить с реализацией и явно обновить источник. Не следует выдавать реконструированный список за согласованный план.

Проверенные области: библиотека и метаданные (`Library`, `AudioMetadata`), Drive (`GoogleDrive`, `drive-ui.js`), браузерные torrent (`torrent*.js`), каталог и модерация (`Catalog`, `AdminCatalog`), главы и CUE (`Chapters`, `ChapterAnalysis`, `CueParser`), воспроизведение и мини-режим (`player.js`, `player-view.js`, `site-player.js`), синхронизация (`Playback`, `playback-sync.js`), публикация (`PublicShare`, `ShareController`), профиль темы и PWA-службы CMS.

## Проверка

`php tests/tape_room_changelog.php` запускает настоящие маршруты, middleware и рендеринг темы в отдельных PHP-процессах с изолированной SQLite-базой. Сетевое соединение и рабочая БД не требуются. Проверяются доступ гостя/пользователя/администратора/создателя, вкладки и записи, покрытие всех версий из Git, архивный статус RC, объяснение ограничений, ссылки между документацией и UI-библиотекой, цели Bootstrap и наличие локальных ресурсов. Временные файлы создаются только в `tests/.tmp/` и удаляются после проверки. Результаты находятся в `tests/artifacts/tape-room-changelog/`. Это серверная проверка; она не заменяет визуальную проверку и взаимодействие с вкладками в браузере.
