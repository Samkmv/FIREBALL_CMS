# Tape Room на maxipapa.ru

Подготовлена версия 1.2.9: независимое вращение катушек, облегчённая отрисовка и запуск облачных индикаторов без повторной отмены загрузки при короткой буферизации. Также сохранены подготовка начала двух следующих песен Google Drive, приватный ограниченный кэш, проверка диапазонов потока, стандартная PNG-обложка для системного плеера, обложки в мобильном списке, выделенные Play и кнопка возвращения, отступы между управлением и шкалой громкости. При выключении звука ползунок показывает ноль. Для индикаторов Safari сохранён отдельный неслышный поток с ограничением скорости и приоритетом основного воспроизведения. Каждый аккаунт CMS имеет свою музыку, избранное, плейлисты и Google-подключение; общие настройки Google доступны только создателю.

## Размещение обновления

1. Архив `reel-player-1.2.9.zip` содержит только каталог `plugins/reel-player`, без конфигурации CMS, пользовательской музыки, Google-секретов и браузерного тестового стенда.
2. Через файловый менеджер хостинга или SFTP распакуйте его в корень установленной CMS, заменяя `plugins/reel-player`. Если на сервере есть собственные изменения этого плагина, предварительно сохраните его текущий каталог. Не заменяйте `storage/reel-player`.
3. В админке откройте **Плагины**, отключите и снова активируйте **Tape Room**. Это применит новые миграции, синхронизирует версию и обновит манифесты. Если плагин ещё не установлен, нажмите **Установить**, затем **Активировать**.
4. Проверьте, что указана версия **1.2.9**. Откройте [плеер](https://maxipapa.ru/admin/reel-player) под создателем и администратором. У администратора будет собственная библиотека.

Штатное обновление через GitHub доступно после публикации этой версии в настроенной ветке `Samkmv/FIREBALL_CMS/main`. Подготовка локального архива не публикует файлы в GitHub или на сервер.

## Подключение Google Drive

1. Войдите на [maxipapa.ru](https://maxipapa.ru/login) под создателем сайта. Откройте **Tape Room → шестерёнка «Настройки плеера» → Google Drive**. Это разовая общая настройка; уже сохранённые реквизиты создателя переносятся автоматически с сохранением его подключения.
2. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект **Tape Room**. В нём включите [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com).
3. Настройте **Google Auth Platform**: название приложения и ваша почта, аудитория **External**. В **Audience → Test users** добавьте почты Google-аккаунтов, которые будут пользоваться плеером, включая администраторов. В **Data Access** добавьте разрешение `https://www.googleapis.com/auth/drive.readonly` — чтение файлов Drive.
4. Откройте **Clients → Create client → Web application**. В **Authorized redirect URIs** добавьте точный адрес:

   ```text
   https://maxipapa.ru/admin/reel-player/drive/callback
   ```

   Если плеер показывает другой адрес, сначала исправьте канонический `PATH` в конфигурации CMS на `https://maxipapa.ru`. Адрес в плеере и Google должны совпадать полностью.
5. Полученные **Client ID** и **Client Secret** вставьте в настройки плеера и нажмите **Сохранить**. Каждый пользователь CMS открывает **Google Drive → Войти в Google Drive**, выбирает собственный Google-аккаунт и разрешает чтение Drive. У администратора нет формы реквизитов; его библиотека и токены принадлежат только ему.
6. В окне Drive отметьте песни или вставьте ссылку на файл / папку. Нажмите **Добавить**. Файлы могут оставаться приватными; плеер читает их через авторизованный серверный маршрут.

В режиме **External / Testing** refresh token истекает через 7 дней, после чего потребуется повторный вход. Для постоянного подключения настройте публикацию приложения с учётом требований Google к выбранному разрешению. При `redirect_uri_mismatch` проверьте точное совпадение адресов, включая HTTPS и отсутствие завершающего слеша.

Официальные документы: [настройка Google Auth Platform](https://developers.google.com/workspace/guides/configure-oauth-consent), [серверный OAuth](https://developers.google.com/identity/protocols/oauth2/web-server), [срок действия токенов](https://developers.google.com/identity/protocols/oauth2#expiration).

## Статус

Архив и настройки интерфейса подготовлены в локальной рабочей копии. Подключение Google-аккаунта и размещение файлов на maxipapa.ru требуют доступа к браузеру / админке / хостингу; их подготовка сама по себе не подтверждает выполненное обновление опубликованного сайта.
