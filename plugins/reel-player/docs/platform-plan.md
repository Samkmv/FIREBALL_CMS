# Tape Room 2.0: план совместимого развития

База реализации — проверенный Tape Room 1.5.1 (`1f4432fd`), сохранённый в локальном `main`. Владелец отправит этот коммит через свой Git-клиент; новые возможности разрабатываются отдельно в `codex/tape-room-2-platform`.

1. Добавить отдельные PublicCatalog и MusicAccessPolicy, миграции распространения 008 и выключенный флаг публичного каталога. Прежнее `published` означает только прежнюю внутреннюю публикацию. Google Drive остаётся доступным в личном/административном плеере, публичная выдача его аудио пока запрещена.
2. Добавить нормализованные жанры/теги, связи, фильтры до серверного COUNT/LIMIT, рекомендации после проверки доступа. Персонализация требует отдельного согласия в настройках.
3. Сохранить оригинальную разметку катушек в общем компоненте, выделить PlaybackCore и добавить компактный интерфейс над тем же основным Audio. Использовать прежние Transport, Meters, Chapters и Preloader. Согласовать Media Session с FirePlayer, добавить серверные предпочтения и постоянный host вне заменяемого содержимого темы.
4. Добавить самостоятельный iframe для явно разрешённой открытой музыки. CSP ограничивает допустимые сайты; Referer не заменяет проверку прав. Закрытые/платные записи не выдаются внешнему виджету.
5. Добавить подтверждение лицензии, отдельный download и связанные разрешённые тарифы. Использовать действующий subscriptions, не менять платежи. Все запросы аудио и обложек проверяют актуальные права до Range/ETag.

Публичные шаблоны рендерятся активной темой CMS. Их CSS ограничен собственным контейнером. Навигация без прерывания доступна только для поддерживаемых музыкальных страниц; полные переходы сохраняют очередь и позицию без обещания бесшовного звука.

Все новые флаги выключены по умолчанию. Миграции только добавочные. Перед применением к рабочей базе необходимо штатное резервное копирование базы и `storage/reel-player`. Сначала проверки выполняются в изолированных данных внутри `tests/.tmp`; результаты — в `tests/artifacts/tape-room-2.0`. Реальный iPhone/PWA/Bluetooth требуют отдельной ручной приёмки.
