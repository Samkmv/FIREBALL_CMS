# Camera Manager

Плагин автоматизирует схему проекта MAXIPAPA:

`камера → регистратор → WireGuard → RTSP → streams.pl/FFmpeg → HLS → сайт`.

Он хранит объекты, регистраторы и каналы в базе FIREBALL CMS, шифрует RTSP-пароли и публикует отдельный управляемый блок `%cam` в существующий `/var/www/html/rtsp/streams.pl`.

## Рекомендуемое подключение для SprintHost

Для виртуального хостинга используется исходящая синхронизация: RTSP-сервер раз в минуту обращается к FIREBALL CMS по HTTPS и забирает новую ревизию. На SprintHost не требуются SSH, `exec`, `proc_open` или доступ к системным каталогам — достаточно загрузить плагин по FTP и активировать его в CMS.

Запросы подписываются случайным 256-битным токеном. В CMS хранится только SHA-256 хеш токена, а его исходное значение находится в root-only конфигурации RTSP-сервера. RTSP URL передаются только в HTTPS-ответе с `Cache-Control: no-store`.

Полная установка: [`server/README.md`](server/README.md).

## Защита существующих камер

Перед каждым применением RTSP-агент:

1. блокирует параллельную публикацию;
2. формирует временный файл в каталоге `streams.pl`;
3. доказывает побайтовую неизменность всего файла за пределами маркеров `FIREBALL CAMERA MANAGER: BEGIN/END`;
4. отклоняет совпадение ключа новой камеры с ручной или старой записью;
5. разрешает внутри блока только RTSP-элементы строгого формата;
6. выполняет `perl -c`;
7. создаёт резервную копию;
8. атомарно заменяет файл и перезапускает `rtsp-streams.service`;
9. автоматически возвращает исходный файл, если служба не запустилась.

Таким образом, первая публикация добавляет новый блок рядом с существующими камерами, а дальнейшие публикации меняют только этот блок.

## Режимы

- `HTTPS pull` — рекомендуется для SprintHost и другого виртуального хостинга.
- `SSH` — альтернативный push-режим с отдельным Ed25519-ключом и forced-command агентом.
- `Локальный файл` — если CMS и RTSP находятся на одном сервере.

## Установка плагина

1. Загрузите каталог `camera-manager` по FTP в каталог `plugins` FIREBALL CMS.
2. В панели FIREBALL CMS откройте «Плагины», установите и активируйте Camera Manager.
3. Откройте «Камеры → Настройки», выберите `HTTPS: RTSP-сервер забирает настройки` и настройте общий токен по инструкции сервера.
4. Сначала запустите агент без камер и убедитесь, что CMS видит его обращение.
5. Создайте объект и камеры, проверьте «Конфигурацию» и нажмите «Опубликовать».

Приватные ключи WireGuard в плагин не вводятся. Изменение `wg0.conf` намеренно не автоматизировано: ошибка в нём может отключить все действующие объекты.
