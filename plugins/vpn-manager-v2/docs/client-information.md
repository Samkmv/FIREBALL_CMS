# Информация о клиенте в подписке (1.5.12)

В админке откройте **Подписки → Открыть → Информация о клиенте**.

Таблица **Использование трафика по серверам** видна сразу: сервер, использовано, Upload, Download, количество подключений и дата проверки. Подключения одного сервера суммируются; чужие и удалённые подключения не включаются. Непроверенные значения показываются как «—», а неполная синхронизация отмечается явно.

Кнопка **Обновить трафик** проверяет принадлежащих подписке клиентов только для чтения, не более двух одновременно. Таблица и карточки **Использовано / Осталось** обновляются вместе. Общий расход — сумма тех же серверных счётчиков, которые показаны в таблице, а не устаревшее поле общего учёта подписки. Проверка отдельного клиента также обновляет сводку; для сервера с несколькими подключениями нужны ответы всех его клиентов. Повторная проверка заменяет снимки, а не добавляет расход повторно. На открытии страницы внешние запросы автоматически не выполняются.

Если сервер или хотя бы одно его подключение недоступны, прежний полный снимок этого сервера остаётся: доступная часть не подменяет его общий расход. При ошибке выводится отдельное предупреждение о неудачной проверке и сохранённых счётчиках. Если счётчиков ещё нет, предупреждение объясняет неполную сумму, а точный остаток ограниченного тарифа не показывается. После успешной проверки всех подключений оба предупреждения скрываются, а дата сводки соответствует самому старому включённому снимку. Свежие и сохранённые данные помечаются разными источниками.

- Сводка показывает расход по всем принадлежащим подписке серверам и остаток **общего лимита подписки**: `max(0, лимит − сумма расхода)`. Нулевой/пустой лимит — **Безлимит**, пустая дата окончания — **Бессрочно**, конечный срок — оставшиеся дни и точная дата окончания. Просроченный срок не становится отрицательным. Подтверждённый нулевой расход — **0 Б**, неизвестный — **—**. Активные/все подключения учитываются отдельно.
- Раскройте подключение, чтобы посмотреть сохранённые Upload/Download, лимит, протокол, транспорт, защиту, Flow, запрошенный доступ CMS и состояние синхронизации. Указана дата проверки; непроверенный нулевой расход отображается как «—». При неполной или неудачной синхронизации показывается предупреждение о сохранённых данных.
- **Проверить данные в 3x-ui** читает текущие данные конкретного клиента: доступ в панели, расход Upload/Download, лимит и остаток, срок, лимиты HWID/IP, последнюю активность и число зарегистрированных HWID-устройств. Глобальная запись клиента имеет приоритет над устаревшей проекцией inbound. Отсутствующая поддержка HWID или отсутствующие поля отображаются как «—», а не как ноль.
- Это отдельная проверка только для чтения: она не запускает очередь, не меняет учёт или лимиты подписки в базе, не сохраняет панельные счётчики в CMS, не меняет клиента и не сбрасывает трафик. После ошибки старые подробные результаты проверки скрываются; последние доступные счётчики остаются видимыми с датой и предупреждением. После перезагрузки снова видны сохранённые в CMS снимки; текущие данные читаются кнопкой обновления. После сброса счётчиков в панели её текущий расход может отличаться от накопленного учёта CMS.
- «Доступ в панели» не означает, что клиент сейчас онлайн. Последняя активность выводится только при наличии такого поля в ответе 3x-ui.

API доступен только администраторам/создателям с правом просмотра плагина. Перед запросом проверяется принадлежность подключения подписке и сервера inbound. Удаляемые и чужие подключения отклоняются. Ответ не содержит UUID/паролей, токенов подписки, идентификаторов HWID и секретов панели; ошибки возвращаются без исходного текста исключения. Ответ не кэшируется.

Проверки без подключения к базе CMS или реальным панелям:

```sh
php plugins/vpn-manager-v2/tests/client_information_unit.php
```

Браузерная проверка использует Playwright и только перехваченные тестовые страницы/ответы. Она проверяет настоящий шаблон CMS в светлой/тёмной теме на ширинах 320–1440 px, успешный запрос, ошибки панели/авторизации/формата, повторную проверку, безопасный вывод текста и HTTP 404 для чужого подключения:

```sh
VPN_TEST_PHP=php node plugins/vpn-manager-v2/tests/client_information_browser.cjs
```
