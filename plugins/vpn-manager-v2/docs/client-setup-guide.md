# Happ и sing-box: инструкция для администратора

VPN Manager V2 1.6.2. Проверено 10 октября 2026 года.

## Сначала выберите, что нужно пользователю

| Что нужно | Happ | Профиль sing-box из плагина |
| --- | --- | --- |
| Обычное подключение с ручным выбором страны | Работает без Provider ID | Работает без Provider ID в совместимом приложении |
| Настроить автоматический выбор при открытии через CMS | Нужен Provider ID Happ | Provider ID не нужен |
| Переключать сервер во время работы при сбое | Через реализованные параметры Happ не подтверждено | Поддерживается движком через проверки; открытый сеанс не переносится на другой сервер |
| Запретить просмотр и экспорт в приложении | Нужен Provider ID и обновление подписки; проверять на устройстве | Такой запрет Happ здесь не действует |
| Сделать уже скопированный ключ непригодным на другом устройстве | Эта настройка не умеет | Эта настройка не умеет |

**Исправление:** ранее я неверно указал, что запрет просмотра в Happ работает без Provider ID. `hide-settings` находится в разделе расширенных параметров Happ, где ID обязателен. В плагине исправлены проверка, передача ID и подсказки. Это требование приложения, а не ID пользователя или сервера в CMS.

## Happ без Provider ID

Если у вас нет Provider ID, обычная подписка остаётся рабочей. Пользователь добавляет её в Happ, самостоятельно выбирает доступную страну и подключается. Получать ID только ради обычного подключения не нужно.

В CMS оставьте **Управлять автоматическим подключением Happ** выключенным. В карточке **Защита подключений в Happ** оставьте **Не менять настройки приложения**. Включение этих функций без выданного Happ ID не обеспечивает их применение. Изменение переключателя CMS также не удаляет ранее выданный локальный ключ из приложения.

## Happ: запрет просмотра и копирования

1. Зарегистрируйтесь в [кабинете Happ](https://happ-proxy.com/) и получите свой **Provider ID**. Это идентификатор вашего сервиса у Happ. Не вводите сюда номер пользователя, номер VPN-сервера, UUID подключения или токен 3x-ui.
2. В CMS откройте **Управление VPN → Ещё → Настройки**.
3. В блоке **Smart Connect → Happ** заполните поле **Provider ID**. Если нужен только запрет копирования, включать Smart Connect и автоматическое подключение не требуется.
4. Ниже, в разделе **Безопасность → Защита подключений в Happ**, выберите **Запретить просмотр и экспорт**.
5. Нажмите **Сохранить**. Если ID не указан, плагин сообщит об этом и не сохранит неподдерживаемую политику.
6. На ноутбуке в Happ обновите **существующую подписку, добавленную по ссылке**. Убедитесь, что обновление прошло успешно. Простое переподключение VPN не загружает новые настройки подписки.
7. Проверьте просмотр и экспорт сервера внутри этой подписки. Согласно документации, Happ должен ограничить просмотр/редактирование и обычную передачу скрытого подключения. Отдельный локальный сервер, ранее импортированный из ключа, к такой подписке уже не относится.

Для возврата просмотра выберите **Разрешить просмотр и экспорт**, сохраните и снова обновите подписку в Happ. Оставьте действующий Provider ID. Режим **Не менять настройки приложения** лишь прекращает передачу политики и не гарантирует снятия уже сохранённого ограничения.

Happ использует Provider ID для обращения к своему сервису; документация перечисляет передаваемые HWID, хеш домена подписки и сведения об ОС. Ознакомьтесь с [описанием Provider ID](https://www.happ.su/main/dev-docs/provider-id). CMS проверяет формат ID, но не может подтвердить его активацию в сервисе Happ.

## Если на ноутбуке с версией 6.0.0 просмотр всё ещё доступен

Сам номер версии не доказывает причину. Последовательно проверьте:

1. Это Happ, а не другое приложение. На сторонний клиент параметр Happ может не действовать.
2. На сайте установлено исправление плагина 1.6.2. Изменения в локальном репозитории сами не обновляют другой сайт.
3. В CMS сохранён реальный Provider ID из кабинета Happ и выбран запрет просмотра/экспорта.
4. Проверяемый сервер находится в подписке, загружаемой по ссылке CMS. Не в отдельном списке локально импортированных ключей.
5. Happ действительно обновил подписку без ошибки. Для активной подписки ограничение устройств также может препятствовать загрузке.
6. Ответ подписки содержит оба параметра: `providerid` и `hide-settings: 1`. При диагностике проверяйте только наличие/значение политики, не публикуйте ссылку или полный ответ с ключами.
7. Если всё перечисленное выполнено, а настройка не применяется, нужны ОС, тип сборки Happ и воспроизводимая проверка на этом устройстве. Тесты CMS не заменяют проверку клиента.

Плагин не выполняет обновление приложения Happ и не проверяет ваш аккаунт в Happ. На физическом ноутбуке версия 6.0.0 в рамках этих тестов не запускалась; исправленная передача параметров проверена автоматически.

## Что такое sing-box

sing-box — VPN-движок; совместимые приложения используют его для подключения. Для него плагин выдаёт **отдельный полный профиль JSON**: список ваших существующих серверов, их ключи и правила выбора. Получать Provider ID Happ для этого не нужно. Устанавливать ещё одну панель на VPN-серверы тоже не нужно.

При включённом автоматическом режиме клиент проверяет узлы **с устройства пользователя через его текущую сеть**. Проверка запрашивает контрольную страницу через каждый VPN-узел: это проверяет прохождение прокси-трафика. Если Германия заблокирована оператором, но Нидерланды доступны, клиент может выбрать Нидерланды. Доступность панели CMS не определяет результат этих проверок.

В режиме резервирования sing-box может сменить выбранный узел при обнаружении сбоя. Это не мгновенное переключение: оно зависит от проверки и работы клиента. Уже открытый TCP-сеанс не переносится; приложение должно установить соединение заново. При смене выбранного узла режим резервирования допускает прерывание существующих соединений.

## Как настроить sing-box без Provider ID

1. В CMS откройте **Управление VPN → Ещё → Настройки → Smart Connect**.
2. Включите **Smart Connect**.
3. Выберите **Автоматически с резервированием · sing-box**, если требуется переключение во время работы. Для обычного автоматического выбора используйте **Автоматически**.
4. Оставьте **Управлять автоматическим подключением Happ** выключенным. Поле Provider ID можно оставить пустым, если отдельно не используется политика просмотра/экспорта Happ.
5. Включите **Разрешить отдельную подписку sing-box JSON**.
6. Для первого теста оставьте интервал **180 секунд** и порог переключения **100 мс**. Сохраните настройки.
7. В карточке подписки администратора либо в **Моих подключениях** пользователя скопируйте отдельную ссылку **Профиль sing-box**. Обычная ссылка Happ и эта ссылка служат разным форматам.
8. В приложении, которое принимает полный sing-box JSON, добавьте ссылку как **удалённый профиль**. Название пункта зависит от приложения. Для этой реализации требуется совместимый движок 1.12+ и поддержка использованных транспортов.
9. Загрузите профиль, выберите его и включите VPN. Для теста переключения подписка должна содержать хотя бы два работоспособных узла.

**Лимит устройств:** если подписка требует HWID, загрузчик профиля обязан передавать `X-HWID`. Без этого CMS откажет в выдаче JSON. Не каждое приложение sing-box умеет передавать этот заголовок; наличие движка sing-box само по себе не доказывает поддержку ограничения устройств. Не снимайте лимит у действующих клиентов ради запуска теста.

Профиль sing-box из этого плагина предназначен для клиента, принимающего полный JSON. Наличие пункта «sing-box» среди движков Happ на компьютере не доказывает, что обычная подписка Happ применит этот профиль и правила резервирования. Такая совместимость отдельно не проверена.

## Как выставлять приоритеты

**Чем меньше число, тем выше приоритет.** Диапазон — 0–1000.

| Сервер | Пример значения |
| --- | --- |
| Германия — первый кандидат | 0 |
| Нидерланды — следующий кандидат | 100 |
| Третий сервер — после первых двух | 1000 |

Приоритет в текущей реализации определяет **порядок кандидатов до результатов измерений**, а не постоянное предпочтение страны. sing-box затем выбирает по успешности проверки и задержке. Значение 0 не заставляет использовать недоступную Германию и не гарантирует её выбор при доступных более быстрых узлах.

Порог **100 мс** помогает удерживать уже выбранный работающий узел при небольших различиях задержки. Это другой параметр: приоритет 100 не означает задержку 100 мс. Порог не удерживает неисправный узел. Интервал 180 секунд задаёт период проверки; он не гарантирует переключение ровно через 180 секунд после любого сбоя.

Текущий механизм не реализует правило «всегда Германия, а Нидерланды только при отказе». Не используйте приоритеты как обещание такой политики. Сохранённый ручной порядок серверов в обычной подписке CMS не меняется.

## Почему запрет просмотра не защищает ключ в любом приложении

Запрет просмотра — команда **интерфейсу Happ**. Для работы VPN приложение всё равно получает данные подключения. sing-box получает открытый JSON с UUID/паролями и не обязан выполнять команды Happ. Поэтому одновременно разрешённый экспорт JSON предоставляет другой способ получить ключи.

Уже скопированный ключ обращается прямо к VPN-серверу. Он может работать без нового обращения к CMS. Лимит HWID ограничивает получение подписки, но в текущих обычных VLESS/VMess/Trojan-подключениях не доказывает физическое устройство при каждом VPN-сеансе.

Оригинал и копия используют того же серверного клиента: общий трафик, срок действия и состояние доступа. Серверное отключение этого клиента затрагивает обоих. Копирование само по себе не отключает ключ. Удаление записи HWID также не означает отзыв уже выданного UUID.

Если вам важнее ограничить обычный экспорт именно в Happ, используйте действующий Provider ID и запрет просмотра, а экспорт sing-box оставьте выключенным. Даже тогда нельзя обещать полную непереносимость ранее полученных ключей или защиту обычной ссылки подписки от другого загрузчика.

Новые настройки не меняют UUID, пароли и постоянные ссылки; действующих клиентов не нужно пересоздавать. Без явного включения новых функций работа остаётся прежней.
