# Автовыбор VPN через Xray

Возможность выключена по умолчанию. Для пилота существующая ссылка получает отдельный вариант с параметром `?format=xray`. Happ получает массив из одного полноценного профиля Xray. Ручные серверы остаются в обычной подписке, которую можно сохранить рядом в Happ.

Если вы добавляли общий JSON-список в версии 3.2.1, обновите эту ссылку после установки 3.2.2. В ней останется только «⚡ Автовыбор». Для ручных и внешних подключений в карточке подписки нажмите **«Скопировать ссылку»** и добавьте обычный адрес без `?format=xray`, если его ещё нет в Happ. Документация Happ описывает обычные списки URI и массивы JSON отдельно. Смешанный формат не подтверждён.

## Настройки

Откройте **Управление VPN → Ещё → Настройки → Автовыбор VPN (Xray)**.

| Настройка | Действие |
| --- | --- |
| Включить автовыбор | Разрешает функцию в CMS. |
| Выдавать отдельную JSON-подписку | Управляет выдачей по адресу с `?format=xray`. |
| Показывать ссылку в профиле клиента | По умолчанию выключено. Администратор может скопировать ссылку в карточке подписки для пилота. |
| Разрешённые серверы 3x-UI | Пустой выбор включает все подходящие подключения пользователя. Указанный список ограничивает только управляемые серверы. |
| Включать совместимые внешние подключения | Берёт актуальные сохранённые конфигурации тарифа и подписки. |
| Стратегия и интервал | По умолчанию `leastPing` и 30 секунд. `leastLoad` использует три образца `burstObservatory` и выбирает один узел. |
| HTTPS-адрес проверки | Публичный адрес, доступный через каждый VPN-узел. Предпочтительно возвращает HTTP 204. CMS его не запрашивает. |
| Тайм-аут | 1–15 секунд для `leastLoad`. `leastPing` использует фиксированные 5 секунд в Xray. |
| Если все серверы недоступны | По умолчанию блокирует трафик. Можно разрешить попытку через первый VPN-узел. Прямого исходящего подключения в профиле нет. |

Карточка подписки показывает количество совместимых и пропущенных конфигураций по локальным данным до проверки устройства. Для фактической выдачи есть заголовки `X-Fireball-Xray-Nodes`, `X-Fireball-Xray-Skipped` и `X-Fireball-VPN-Status`. Заголовки не содержат ключей.

## Выдача и ограничения

Плагин использует тот же токен, доступ к тарифу, срок, ограничения устройства и активные зависимости, что и обычная подписка. JSON отдаётся только по HTTPS без кэша. После добавления, удаления или обновления источника Happ должен перечитать JSON-ссылку. При истечении срока или отсутствии подходящих подключений профиль обновляется на конфигурацию без учётных данных, блокирующую трафик. Выгруженная ранее копия подчиняется проверкам на самих VPN-серверах. Внешний поставщик отвечает за отзыв своих ключей.

Поддерживаются VLESS + REALITY с обычным TCP/RAW. Каждый узел сохраняет свой адрес, порт, UUID, SNI, ключ REALITY и параметры транспорта. Остальные подключения пропускаются и доступны через обычную ссылку. Профиль использует локальный SOCKS с UDP. Обычные запросы DNS на порт 53, попавшие в SOCKS, направляются в DoH через балансировщик. Первичное разрешение домена VPN-узла зависит от системного резолвера. Настройки DNS вне туннеля управляются Happ и iOS.

`leastPing` выбирает узел для нового соединения по результатам HTTP-проверок. Он не измеряет скорость скачивания и не переносит открытые TCP-сессии. У стратегии нет настраиваемого гистерезиса. `leastLoad` использует несколько образцов для оценки стабильности. Выбор после смены сети обновится, пока ядро работает или после его повторного запуска. Восстановление туннеля зависит от Happ и iOS. Блокировка при отказе всех серверов действует внутри Xray, пока туннель принимает трафик. Поведение iOS вне туннеля требует проверки на устройстве.

Источники: [Observatory](https://xtls.github.io/en/config/observatory.html), [Routing](https://xtls.github.io/en/config/routing.html), [DNS Xray](https://xtls.github.io/en/config/dns.html), [формат JSON Happ](https://www.happ.su/main/dev-docs/examples-of-links-and-parameters).

## Проверка в Happ на iPhone

1. Обновите плагин на тестовой CMS с HTTPS. Если TLS завершает обратный прокси, проверьте, что CMS распознаёт его по своим настройкам доверенных прокси.
2. Включите автовыбор и выдачу JSON. Оставьте показ ссылки клиентам выключенным. Создайте тестовую подписку минимум с двумя действующими VLESS + REALITY TCP-подключениями. Если используется лимит устройств, проведите проверку с включённым лимитом.
3. Откройте карточку подписки и нажмите **Скопировать ссылку Xray**. В Happ добавьте её как отдельную подписку, выберите **⚡ Автовыбор** и включите туннель. Сохраните обычную подписку для сравнения.
4. Проверьте HTTPS-страницу с доменным именем, UDP-трафик и внешний IP через контролируемый тестовый ресурс. Сверьте DNS по журналу тестового резолвера или сетевому захвату. На этапе пилота используйте только тестовые ключи.
5. Временно сделайте один тестовый узел недоступным для телефона. Через один-два интервала откройте новое соединение и проверьте IP резервного узла. Затем заблокируйте все тестовые узлы и проверьте, что у включённого туннеля нет прямого выхода.
6. Переключите телефон с мобильной сети на Wi-Fi. Если Happ остановил туннель, запустите его вручную. Проверьте выбор узла после новых проб. Повторите тест после добавления и удаления узла, обновляя именно JSON-подписку в Happ.
7. При ошибке запуска JSON вернитесь к обычной подписке и сохраните версию Happ, iOS и текст ошибки. UUID, ссылки и параметры REALITY передавать не требуется.

## Откат

Выключите автовыбор в настройках. На телефоне отключите тестовый профиль и удалите отдельную JSON-подписку из Happ. Обычная подписка работает по прежней ссылке. При необходимости верните предыдущую версию плагина штатным способом. Настройки добавлены в существующее хранилище плагина.

## Повторение локальных проверок

```sh
php tests/vpn_xray_auto_unit.php
php plugins/vpn-manager-v2/tests/plan_external_sources_unit.php
mkdir -p tests/.tmp
scratch=$(mktemp -d "$PWD/tests/.tmp/xray-verify.XXXXXXXX")
php tests/vpn_xray_auto_unit.php leastPing > "$scratch/leastPing.json"
php tests/vpn_xray_auto_unit.php leastLoad > "$scratch/leastLoad.json"
xray run -test -config "$scratch/leastPing.json"
xray run -test -config "$scratch/leastLoad.json"
python3 tests/vpn_xray_auto_lab.py "$(command -v xray)" "$scratch/leastPing.json"
```

Лаборатория запускает только локальные узлы. Ей нужны Python 3, Node.js, OpenSSL и curl. После проверки удалите созданную папку `scratch`. [Пример конфигурации](xray-auto.example.json) использует вымышленные домены и учётные данные.
