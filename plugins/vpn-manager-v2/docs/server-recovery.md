# Замена и восстановление VPN-сервера

После добавления или редактирования сервера открывается страница **Проверить и восстановить**. Она также доступна в меню действий **⋮** у сервера в разделе **Серверы**.

1. **Проверить панель.** Загружаются подключения (inbounds) текущей панели 3x-ui. Проверка не удаляет отсутствующих клиентов.
2. **Выбрать подключения.** Если у новой панели другие идентификаторы подключений, выберите замену для каждого подключения, используемого тарифами. Протокол должен совпадать. Объединение нескольких старых подключений в одно занятое запрещено.
3. **Восстановить подписки.** Для действующих подписок выполняется существующее согласование тарифа, создание отсутствующих клиентов, обновление параметров и проверка фактического состояния в 3x-ui. Это действие разрешает восстановление клиентов, архивированных после исчезновения из панели. Сохраняются локальные номера подключений, UUID/пароли, subId, токены ссылок подписок и накопленный учёт трафика. Приостановленные подписки остаются отключёнными, истёкшие не восстанавливаются.
4. **Проверить результат.** Результат отображается отдельно для каждой подписки. **Повторить ошибки** повторяет только неудачные операции; **Продолжить незавершённые** обрабатывает очередь после закрытия страницы. Настроенный обработчик очереди также может завершить операции в фоне.

Если настройки сервера изменились повторно, нужно снова проверить панель и начать восстановление. Операция, запущенная для прежних настроек, не записывает клиентов в новую панель. Предыдущие результаты не считаются результатом новой настройки.

## Новый сервер

Создание сервера само по себе не меняет подписки. После проверки панели добавьте нужное подключение сервера в тариф. Затем вернитесь на страницу восстановления сервера и выполните шаги 2–4 для существующих подписок этого тарифа. Новые подписки используют текущий состав тарифа.

## Удаление и отключение

Удалить запись сервера можно, только если у неё нет ссылок из тарифов и подключений подписок, включая архивные. Количество ссылок показано на странице восстановления. Удаление записи в CMS не удаляет панель 3x-ui и клиентов в ней.

Отключение сервера исключает его конфигурации из выдаваемых подписок. Оно не удаляет клиентов из 3x-ui. Для отключения доступа ранее импортированных клиентов используются действия управления подпиской или подключением.

## Проверка всех панелей

Дополнительное действие в разделе **Операции** считывает состояние панелей, обновляет конфигурации и обнаруживает расхождения. После замены сервера используйте пошаговое восстановление, чтобы явно выбрать новые подключения и восстановить архивных клиентов.
