# Индикация действий VPN (1.5.10)

При запуске проверки панелей, повтора ошибок, обработки очереди или отмены задачи кнопка и сообщение показывают индикатор обработки. Остальные асинхронные действия и очистка таблицы временно заблокированы. Повторный submit во время обработки не отправляет новый запрос.

Завершение, частичный результат, отмена и отложенная повторная попытка показываются раздельно. Полная проверка выводит фактические счётчики и безопасную причину ошибки. Ожидающая/работающая задача проверяется только чтением статуса; POST автоматически не повторяется. Отложенный retry завершает ожидание с предупреждением, а не изображает успешное выполнение. При потере статуса требуется проверить раздел «Операции» перед новым запуском.

После ответа обновляется только блок таблицы операций из штатного авторизованного представления CMS. Страница, раскрытые дополнительные действия и текущая пагинация сохраняются. Ошибка обновления таблицы не стирает результат действия. Защита подтверждения сброса трафика и очистки сохранена.
