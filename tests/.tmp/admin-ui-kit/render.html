UI-компоненты

Единый каталог для настройки интерфейса и новых страниц админки.

Примеры используют общие стили админки. Светлая и тёмная темы переключаются в верхней панели.

Демонстрационные данные. Формы и действия на этой странице не изменяют сайт.

  • Цвета и типографика
  • Отступы, скругления и тени
  • Кнопки
  • Поля формы
  • Выбор и переключатели
  • Состояния и валидация
  • Карточки и показатели
  • Таблицы и списки
  • Навигация
  • Статусы и уведомления
  • Окна и подсказки
  • Пустые состояния и загрузка
  • Иконки
  • Использование на новых страницах

По этому запросу компонентов нет. Попробуйте другое название или CSS-класс.

Использование на новых страницах

Обёртка страницы

Общие стили подключаются на всех admin-маршрутах. Используйте shell и готовые partials.

Общий внешний вид меняйте в admin-ui.css; поведение оболочки — в admin-ui.js. Стили каталога находятся отдельно.

Пользовательский текст выводите через htmlSC(), ссылки создавайте через base_href(), а в рабочих формах сохраняйте get_csrf_field().

Код компонента
HTML / PHP 
<?= view()->renderPartial('admin/shell_open', [
    'title' => return_translation('my_page_title'),
    'subtitle' => return_translation('my_page_subtitle'),
]) ?>

<div class="fb-card">
    <div class="fb-card-header">
        <h2 class="fb-card-title"><?= htmlSC($heading) ?></h2>
    </div>
    <div class="fb-card-body">
        <form method="post" action="<?= base_href('/admin/my-page') ?>">
            <?= get_csrf_field() ?>
            <!-- Form fields -->
            <button class="btn btn-primary" type="submit">
                <?= htmlSC(return_translation('admin_settings_save')) ?>
            </button>
        </form>
    </div>
</div>
